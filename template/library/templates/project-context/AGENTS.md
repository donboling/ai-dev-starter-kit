# Project instructions

Read `.agent/STATUS.md` and `.agent/HANDOFF.md` before beginning. Keep the change scoped to the task and verify changed behavior. Follow this project's package manager and conventions; use `README.md` for setup commands.

Keep durable architecture in `docs/architecture.md` and record consequential decisions in `docs/decisions/`. At the end of a meaningful session, update `.agent/HANDOFF.md` with the change, checks, risks, and the next concrete task. Never commit secrets or an `.env` containing credentials.
