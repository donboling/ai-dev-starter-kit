# Git rescue

Inspect `git status -sb`, recent history, branches, remotes, and the affected diff before changing anything. Preserve uncommitted work. Prefer a focused restore or revert where possible. Explain whether commits were published before rewriting history; never force-push or discard unrelated changes as a shortcut. Verify the final diff and status.
