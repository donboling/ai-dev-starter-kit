# Catch up

Read root AGENTS.md, `.agent/STATUS.md`, `.agent/HANDOFF.md`, `.agent/BACKLOG.md`, and `git status -sb`. Scan recent commits and relevant architecture notes. If notes conflict with code, verify and correct them. Summarize the current state, blockers, and next actionable task. Do not change project files merely to answer a status question.
